# Вебзастосунок управління готелем («Готель»)

## Призначення
Вебзастосунок призначений для адміністраторів готелю для автоматизації обліку номерного фонду, оформлення бронювань, контролю доступності номерів та формування звітів.

## Рівень складності
Високий (10–12 балів)

## Технології
- HTML5, CSS3, JavaScript (ES6+)
- Live Server та json-server
- Git (система контролю версій)

## Заплановані функції
1. CRUD для номерів і бронювань.
2. Пошук та фільтрація номерів.
3. Бронювання та заселення з перевіркою доступності.
4. Звіти та експорт даних.
