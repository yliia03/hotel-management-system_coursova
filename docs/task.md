# Постановка завдання на курсовий проєкт

## 1. Тема проєкту
Вебзастосунок управління системою бронювання та заселення в готелі («Готель»).

## 2. Автор і група
- **Здобувач освіти:** Дужак Ю.А.
- **Група:** ІС-23-01
- **Спеціальність:** 126 «Інформаційні системи та технології»
- **Керівник:** Ковальчук В. Я.

## 3. Призначення програми
Програма призначена для адміністраторів готелю з метою автоматизації процесу обліку номерного фонду, бронювання номерів, реєстрації заселення гостей, контролю доступності вільних номерів, а також формування підсумкових звітів та експорту даних.

## 4. Обраний рівень складності
Високий рівень (10–12 балів).

## 5. Основні функції (відповідно до рівня)
- **Облік даних (Середній рівень):** додавання, перегляд, редагування та видалення записів про номери готелю та бронювання; збереження даних; перевірка коректності введення.
- **Предметна логіка та пошук (Достатній рівень):** пошук і фільтрація номерів за категорією або ціною; виконання основної операції предметної області — **бронювання номера та заселення** з автоматичною перевіркою доступності вільних місць/номерів.
- **Звіти та додаткові функції (Високий рівень):** формування підсумкових показників та звітів (наприклад, заповненість готелю, статистика бронювань), реалізація корисної функції — **експорт даних** або перегляд історії операцій; модульна структура коду та опрацювання типових помилок без аварійного завершення.

## 6. Дані, які зберігатимуться (`db.json`)
1. **Номери (`rooms`):** ідентифікатор (`id`), номер кімнати (`roomNumber`), категорія (`category` — стандарт, люкс тощо), кількість місць (`capacity`), вартість доби (`price`), статус (`status` — вільний, зайнятий).
2. **Бронювання / Заселення (`bookings`):** ідентифікатор (`id`), ID номера (`roomId`), ПІБ гостя (`guestName`), дата заїзду (`checkInDate`), дата виїзду (`checkOutDate`), статус бронювання (`status`).

## 7. Важлива перевірка даних або правило роботи
«Дата виїзду має бути пізнішою за дату заїзду, а номер не може бути заброньований, якщо він уже зайнятий на обраний період».
